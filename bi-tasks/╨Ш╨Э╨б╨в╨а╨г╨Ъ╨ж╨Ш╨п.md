# Инструкция по запуску BI Tasks
## Без знания программирования — просто следуйте шагам

---

## ШАГ 1 — Зарегистрируйтесь на трёх сайтах (10 минут)

Откройте три вкладки и зарегистрируйтесь бесплатно:

1. **GitHub** → https://github.com  
   (хранит код)

2. **Supabase** → https://supabase.com  
   (база данных + авторизация)

3. **Vercel** → https://vercel.com  
   (публикует сайт в интернете)

---

## ШАГ 2 — Создайте базу данных в Supabase (5 минут)

1. Зайдите на supabase.com → войдите → нажмите **New project**
2. Введите название: `bi-tasks`, придумайте пароль (сохраните его!)
3. Выберите регион: **Frankfurt** (ближайший к Казахстану)
4. Подождите ~2 минуты пока проект создаётся
5. Когда создался → нажмите **SQL Editor** в левом меню
6. Нажмите **New query**
7. Откройте файл `supabase_schema.sql` из папки проекта
8. Скопируйте всё содержимое и вставьте в редактор
9. Нажмите **Run** (зелёная кнопка)
10. Должно появиться "Success" — база готова!

### Сохраните ключи Supabase:
- Нажмите **Settings** → **API**
- Скопируйте и сохраните:
  - `Project URL` (выглядит как https://xxxx.supabase.co)
  - `anon public` ключ (длинная строка)

---

## ШАГ 3 — Загрузите код на GitHub (5 минут)

1. Зайдите на github.com → нажмите **+** → **New repository**
2. Название: `bi-tasks`
3. Нажмите **Create repository**
4. На следующей странице нажмите: **uploading an existing file**
5. Перетащите ВСЮ папку `bi-tasks` в браузер
6. Нажмите **Commit changes**

---

## ШАГ 4 — Создайте файл с ключами

В папке проекта создайте файл `.env` (именно с точкой в начале):

```
VITE_SUPABASE_URL=https://ваш-url.supabase.co
VITE_SUPABASE_ANON_KEY=ваш-anon-ключ
```

Замените значения на те, что сохранили в Шаге 2.
Этот файл тоже загрузите на GitHub (или добавьте в Vercel на следующем шаге).

---

## ШАГ 5 — Опубликуйте сайт на Vercel (5 минут)

1. Зайдите на vercel.com → войдите через GitHub аккаунт
2. Нажмите **Add New** → **Project**
3. Найдите `bi-tasks` в списке → нажмите **Import**
4. Раскройте раздел **Environment Variables** и добавьте:
   - `VITE_SUPABASE_URL` = ваш URL из Supabase
   - `VITE_SUPABASE_ANON_KEY` = ваш ключ из Supabase
5. Нажмите **Deploy**
6. Через ~2 минуты сайт будет доступен по адресу типа `bi-tasks.vercel.app` 🎉

---

## ШАГ 6 — Зарегистрируйте Зубова Максима как руководителя

1. Откройте сайт `bi-tasks.vercel.app`
2. Зарегистрируйтесь с email Зубова (через форму входа → "Нет аккаунта? Обратитесь...")
3. **Важно**: После регистрации нужно вручную назначить роль "шеф":
   - Вернитесь в Supabase → **SQL Editor** → **New query**
   - Вставьте этот код (замените email):
   ```sql
   update public.profiles
   set full_name = 'Зубов Максим', role = 'chief'
   where id = (select id from auth.users where email = 'zubov@bi.kz');
   ```
   - Нажмите **Run**

---

## ШАГ 7 — Добавьте менеджеров

В Supabase → **Authentication** → **Users** → **Invite user**:
- Введите email менеджера
- Они получат письмо и сами зайдут и зарегистрируются

Затем в SQL Editor обновите их имена:
```sql
update public.profiles
set full_name = 'Рамазан'
where id = (select id from auth.users where email = 'ramazan@bi.kz');
```

---

## Готово! Что теперь умеет система:

✅ Вход по email и паролю — посторонние не зайдут  
✅ Зубов видит все проекты и задачи  
✅ Менеджеры видят только свои проекты  
✅ Шефа назначает задачи, менеджер отмечает шаги  
✅ Прогресс обновляется в реальном времени  
✅ Работает на телефоне и компьютере  
✅ Бесплатно навсегда для вашей команды
